# Wagglet handoff patterns

Practical notes for teams that hand coding-agent work between people without sharing AI accounts, permanent credentials, or ambiguous task ownership.

These guides describe reusable coordination patterns:

- [Bounded context packets](bounded-context-packets.md)
- [Claim-before-work concurrency](claim-before-work.md)
- [Evidence-based delivery](evidence-based-delivery.md)
- [Safe blockers and resumable handoffs](safe-blockers.md)
- [Least-authority task delegation](least-authority-delegation.md)
- [Approval gates for external actions](approval-gates.md)
- [Idempotent recurring workflows](idempotent-recurring-work.md)

The patterns are tool-independent. [Wagglet](https://wagglet.com/) is one implementation built around exact task handoffs, explicit claims, task-scoped context, and structured delivery.
